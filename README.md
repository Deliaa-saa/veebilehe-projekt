# veebilehe-projekt
See on meie rühmatöö tutvustus. 
Selle lehe eesmärk on aidata ettevõttel efektiivsemalt ennast klientidele promoda. Leht sisaldab ettevõtte tooteid (kontoritarbeid, mida müüakse), info firma kohta, ostutingimused ja kontaktid. Alamlehed, igal lehel on erinev kategooria, ostutingimused, kontaktid jne. Toodete jaoks on rippmenüü, kus on erinevad toodete liigid + ostukorv.
